# slot_monitor

Монитор свободных дат **теоретического экзамена** в приложении «ЦОН» (Казахстан), пакет Android `kz.gov4c.citizen`.

## Статус

**Прототип на Ubuntu + Android Debug Bridge (ADB). Не автономное Android-приложение.**

Этот код восстановлен по предыдущему обсуждению; оригинальный локальный файл `~/con-apk/slot-monitor.sh` здесь недоступен. Прототип требует проверки на реальном телефоне, и **не подтверждено**, что повторное открытие даты всегда делает новый сетевой запрос, а не показывает кэш.

В планах — автономный Android APK, работающий через Accessibility Service без компьютера и Shizuku. На текущий момент APK нет.

## Как работает

1. Телефон подключен к ADB и находится на **шаге 2 из 3** записи в ЦОН, выбран нужный спецЦОН.
2. Скрипт открывает «Выберите дату» и анализирует Android UI-дерево.
3. Если обнаружено «Нет доступных дат», закрывает окно, ждёт заданный интервал (по умолчанию 300 секунд).
4. Если вместо сообщения об отсутствии дат найдено изменение интерфейса, отправляет **предупреждение о возможных датах** и снимок экрана (если возможно), затем останавливается для ручной проверки.
5. При неизвестном экране, потере ADB и иных ошибках **не пытается обходить блокировку или подтверждать запись**.

Сообщение о возможных датах **не является доказательством**, что слот действительно появился: возможны изменения интерфейса, ошибки сети, истечение сессии и кэш.

## Быстрый запуск (Ubuntu)

Требуется `adb`, `curl`, `bash`, телефон с разрешённой отладкой, открытое приложение ЦОН на втором шаге и Telegram-бот с ID чата.

```bash
sudo apt install adb curl
git clone https://github.com/namkos567/slot_monitor.git
cd slot_monitor
cp telegram.env.example telegram.env
nano telegram.env
chmod 600 telegram.env
chmod +x slot-monitor.sh
adb devices
./slot-monitor.sh
```

Заполните **настоящие** `BOT_TOKEN` и `CHAT_ID` в `telegram.env`. Этот файл исключён из Git. При нескольких устройствах задайте `ADB_SERIAL`.

Проверка текущего местоположения шага и кнопки обязательна; координаты тапа `540,1232` взяты из предыдущего теста для конкретного разрешения экрана. У других устройств координаты могут отличаться.

## Конфигурация

- `INTERVAL=300` — период проверок (секунды)
- `TAP_X=540`, `TAP_Y=1232` — точка открытия окна выбора даты
- `ADB_SERIAL` — идентификатор устройства (необязательно)
- `BOT_TOKEN`, `CHAT_ID` — Telegram
- `WAKE_DEVICE=0` — по умолчанию не управлять блокировкой телефона

## Ограничения

- Нужен подключённый телефон и доступ ADB; по USB или по ADB Wi-Fi.
- Не работает сквозь экран блокировки, PIN или экран входа; не вводит секреты.
- Сервис «ЦОН» может изменять UI или данные; скрипт намеренно останавливается при неопределённости.
- Не выполняет автоматическую запись на экзамен.
- Следите за правилами сервиса и не сокращайте интервал до агрессивного опроса.

## Безопасность

Не коммитьте `telegram.env`, токены, номера документов, скриншоты или логи с персональными данными. Для максимальной приватности измените видимость репозитория на **Private** через GitHub Settings.
